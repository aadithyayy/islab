Classical Ciphers — ciphers/
01

Caesar Cipher

Shifts every letter by a fixed key of 3. Decryption shifts back by the same amount.

ciphers/caesar.py
Algorithm — Encryption
  1. Start.
  2. Read plaintext. Convert to uppercase. Set key = 3.
  3. For each character ch:
    • Encrypted char = (ord(ch) - 65 + key) % 26 + 65.
    • Append to ciphertext string.
  4. Print encrypted text.
  5. Stop.
Algorithm — Decryption
  1. Start.
  2. For each character ch in ciphertext:
    • Decrypted char = (ord(ch) - 65 - key) % 26 + 65.
    • Append to plaintext string.
  3. Print decrypted text.
  4. Stop.
02

Affine Cipher

Uses the formula E(x) = (a*x + b) mod 26. Decryption requires the modular inverse of a.

ciphers/affine.py
Algorithm — Encryption
  1. Start.
  2. Read plaintext (convert to uppercase), and keys a, b.
  3. For each character ch:
    • Encrypted char = (a * (ord(ch) - 65) + b) % 26 + 65.
    • Append to ciphertext string.
  4. Print encrypted text.
  5. Stop.
Algorithm — Decryption
  1. Start.
  2. Find a_inv: loop i from 0 to 25, find i where (a * i) % 26 == 1.
  3. For each character ch in ciphertext:
    • Decrypted char = (a_inv * (ord(ch) - 65 - b)) % 26 + 65.
    • Append to plaintext string.
  4. Print decrypted text.
  5. Stop.

04

Hill Cipher

Encrypts pairs of letters using a fixed 2x2 key matrix and matrix multiplication mod 26. (Encryption only.)

ciphers/hill.py
Algorithm — Encryption
  1. Start.
  2. Read plaintext. Convert to uppercase. (Length must be even; pad with X if odd.)
  3. Use key matrix k = [[3,3],[2,5]].
  4. Process plaintext in steps of 2. For each pair at index i:
    • p1 = ord(text[i]) - 65, p2 = ord(text[i+1]) - 65
    • c1 = (k[0][0]*p1 + k[0][1]*p2) % 26 + 65
    • c2 = (k[1][0]*p1 + k[1][1]*p2) % 26 + 65
    • Append chr(c1) + chr(c2) to ciphertext.
  5. Print encrypted text.
  6. Stop.

05

RSA Encryption & Decryption

Asymmetric cipher. Keys derived from two primes; encryption and decryption use modular exponentiation.

rsa.py
Algorithm — Key Generation
  1. Start.
  2. Input two primes p and q.
  3. Compute n = p * q.
  4. Compute phi = (p-1) * (q-1).
  5. List all valid e in range (2, phi) where gcd(e, phi) == 1. Print list.
  6. User picks an e. Compute d = mod_inverse(e, phi).
  7. Print public key (e, n) and private key (d, n).
  8. Stop.
Algorithm — Encrypt & Decrypt
  1. Start.
  2. Input message as integer m.
  3. Encrypt: c = pow(m, e, n). Print ciphertext.
  4. Decrypt: dec = pow(c, d, n). Print decrypted message.
  5. Stop.
06

RSA Digital Signature

Signs a message by hashing with SHA-256 then signing the hash with the private key. Verifies by decrypting with the public key.

rsa_sign.py
Algorithm — Key Setup
  1. Start.
  2. Input primes p, q. Compute n = p*q, phi = (p-1)*(q-1).
  3. Input e. Compute d = mod_inverse(e, phi).
  4. Stop.
Algorithm — Signing
  1. Start.
  2. Input message string m.
  3. Hash: h = int(sha256(m.encode()).hexdigest(), 16). Print hash.
  4. Sign: sign = pow(h, d, n). Print signature.
  5. Stop.
Algorithm — Verification
  1. Start.
  2. Decrypt: verify = pow(sign, e, n).
  3. If verify == h % n → print "signature valid".
  4. Else → print "signature invalid".
  5. Stop.
Hash Functions
07

SHA-256 & Avalanche Effect

Hashes two strings with SHA-256 and counts the differing bits between the digests to demonstrate the avalanche effect.

sha.py
Algorithm
  1. Start.
  2. Input strings s1 and s2.
  3. Compute h1 = sha256(s1.encode()).hexdigest(). Print.
  4. Compute h2 = sha256(s2.encode()).hexdigest(). Print.
  5. XOR the two digests as integers: x = int(h1, 16) ^ int(h2, 16).
  6. Count differing bits: bin(x).count('1'). Print result.
  7. Stop.

File Copy using OS System Calls

Copies a file using low-level OS file descriptors (os.open, os.read, os.write) with a 1024-byte buffer.

filecopy.py
Algorithm
  1. Start.
  2. Input source filename and destination filename.
  3. Open source read-only: src = os.open(source, O_RDONLY).
  4. Open/create destination: dest = os.open(destination, O_WRONLY | O_CREAT | O_TRUNC, 0o644).
  5. Read 1024 bytes: data = os.read(src, 1024).
  6. Write to destination: os.write(dest, data).
  7. Close both descriptors: os.close(src), os.close(dest).
  8. Print "File copied successfully".
  9. Stop.

09

Display Files with Date

Lists all regular files in the current directory with a serial number and last-modified date.

shell/displayfiles.sh
Algorithm
  1. Start.
  2. Initialize counter i = 1.
  3. Loop over every entry in the current directory: for file in *.
  4. If entry is a regular file ([ -f "$file" ]):
    • Get modified date: stat -c %y "$file", cut to keep date part only.
    • Print: i. filename - date.
    • Increment i.
  5. Repeat for all entries.
  6. Stop.
10

File Integrity Check

Generates and stores a SHA-256 hash of a file, then verifies that the file has not been modified.

shell/integrity.sh
Algorithm
  1. Start.
  2. Prompt "Enter filename:". Read filename into file.
  3. Compute hash and store: sha256sum "$file" > hash.txt.
  4. Print "Hash stored in hash.txt".
  5. Verify: sha256sum -c hash.txt.
    • If unchanged → prints "filename: OK".
    • If modified → prints "FAILED".
  6. Stop.
11

User Login Monitor

Monitors and detects when a specified user logs into the system by polling who every 30 seconds.

shell/userlogin.sh
Algorithm
  1. Start.
  2. Prompt "Enter username:". Read into user.
  3. Enter infinite loop:
    • Run who | grep -w "$user".
    • If user found → print "User has logged in." Break loop.
    • Else → print "User not logged in. Checking again in 30s..." then sleep 30.
  4. Stop.
