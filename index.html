Classical Ciphers
01

Caesar Cipher

Monoalphabetic substitution — each letter is shifted by a fixed key value.

ciphers/caesar.py
Algorithm — Encryption
  1. Start.
  2. Read plaintext message and shift key k.
  3. For each character c in the message:
    • If letter → replace with character at position (ord(c) − base + k) mod 26.
    • If not a letter → keep unchanged.
  4. Append transformed character to ciphertext.
  5. Print ciphertext.
  6. Stop.
Algorithm — Decryption
  1. Start.
  2. Read ciphertext and shift key k.
  3. Apply encryption algorithm with shift 26 − k (or −k mod 26).
  4. Print recovered plaintext.
  5. Stop.
02

Vigenère Cipher

Polyalphabetic substitution — shift of each letter is determined by a repeating keyword.

ciphers/vigenere.py
Algorithm — Encryption
  1. Start.
  2. Read plaintext and keyword. Convert keyword to uppercase.
  3. Initialize keyword index j = 0.
  4. For each character c in plaintext:
    • If letter → shift by ord(key[j mod len(key)]) − ord('A').
    • Increment j only for letter characters.
    • Append encrypted character to ciphertext.
  5. Print ciphertext.
  6. Stop.
Algorithm — Decryption
  1. Start.
  2. Read ciphertext and keyword.
  3. For each character, subtract the keyword shift instead of adding.
  4. Take result mod 26 to handle wrap-around.
  5. Print plaintext.
  6. Stop.
03

Playfair Cipher

Digraph substitution cipher using a 5×5 key matrix. Encrypts pairs of letters.

ciphers/playfair.py
Algorithm — Key Matrix Construction
  1. Start.
  2. Read keyword. Remove duplicate letters. Treat I and J as the same.
  3. Fill a 5×5 matrix with keyword letters first, then remaining alphabet letters.
  4. Stop.
Algorithm — Encryption
  1. Start.
  2. Prepare plaintext: remove spaces, replace J with I, insert X between duplicate letters in a pair, pad with X if length is odd.
  3. Split into digraphs (pairs of two letters).
  4. For each pair (a, b), find their row and column in the matrix:
    • Same row → replace each with the letter to its right (wrap around).
    • Same column → replace each with the letter below it (wrap around).
    • Rectangle → swap columns: a takes b's column, b takes a's column.
  5. Concatenate all encrypted pairs and print ciphertext.
  6. Stop.
04

Hill Cipher

Block cipher using matrix multiplication over integers mod 26.

ciphers/hill.py
Algorithm — Encryption
  1. Start.
  2. Read plaintext and an n×n key matrix K.
  3. Convert plaintext to numeric vector (A=0, B=1, …, Z=25).
  4. Split vector into blocks of size n. Pad with zeros if needed.
  5. For each block P, compute ciphertext block: C = (K × P) mod 26.
  6. Convert numeric result back to letters.
  7. Print ciphertext.
  8. Stop.
Algorithm — Decryption
  1. Start.
  2. Compute the modular inverse of key matrix K mod 26.
  3. For each ciphertext block C, compute: P = (K⁻¹ × C) mod 26.
  4. Convert back to letters and print plaintext.
  5. Stop.
05

Rail Fence Cipher

Transposition cipher — plaintext is written in a zigzag across n rails.

ciphers/rail_fence.py
Algorithm — Encryption
  1. Start.
  2. Read plaintext and number of rails n.
  3. Create n empty strings (one per rail).
  4. Traverse plaintext: assign each character to a rail in zigzag order (0→n−1→0→…).
  5. Concatenate all rails in order to form ciphertext.
  6. Print ciphertext.
  7. Stop.
Algorithm — Decryption
  1. Start.
  2. Determine the length each rail holds by simulating the zigzag pattern.
  3. Split ciphertext into rail segments according to those lengths.
  4. Re-traverse the zigzag, reading one character from each rail's segment in order.
  5. Print recovered plaintext.
  6. Stop.
06

Columnar Transposition Cipher

Plaintext is arranged in a grid; columns are rearranged according to the key order.

ciphers/columnar.py
Algorithm — Encryption
  1. Start.
  2. Read plaintext and keyword of length k.
  3. Pad plaintext with X to make its length a multiple of k.
  4. Arrange padded text row-by-row in a grid with k columns.
  5. Determine column order by sorting the keyword letters alphabetically.
  6. Read columns in sorted keyword order and concatenate to form ciphertext.
  7. Print ciphertext.
  8. Stop.
Algorithm — Decryption
  1. Start.
  2. Determine number of rows: ceil(len(ciphertext) / k).
  3. Determine sorted column order from keyword.
  4. Split ciphertext into columns of appropriate length.
  5. Re-insert columns into a grid at their original positions (reverse sorted order).
  6. Read grid row-by-row and strip padding to get plaintext.
  7. Stop.
Public Key Cryptography
07

RSA Encryption & Decryption

Asymmetric cipher based on the difficulty of factoring large integers.

rsa.py
Algorithm — Key Generation
  1. Start.
  2. Input two prime numbers p and q.
  3. Compute n = p × q (modulus).
  4. Compute Euler's totient: φ(n) = (p−1) × (q−1).
  5. Find all valid public exponents e where 2 < e < φ(n) and gcd(e, φ(n)) = 1.
  6. Choose an e from the list.
  7. Compute private key d = e⁻¹ mod φ(n) using mod_inverse(e, φ).
  8. Public key: (e, n). Private key: (d, n).
  9. Stop.
Algorithm — Encrypt & Decrypt
  1. Start.
  2. Input message as integer m.
  3. Encrypt: c = me mod n using pow(m, e, n).
  4. Print ciphertext c.
  5. Decrypt: m = cd mod n using pow(c, d, n).
  6. Print decrypted message.
  7. Stop.
08

RSA Digital Signature

Sign a message with the private key; verify authenticity using the public key.

rsa_sign.py
Algorithm — Signing
  1. Start.
  2. Generate RSA keys (e, d, n) as in the RSA algorithm above.
  3. Read the message string.
  4. Compute hash: h = int(SHA-256(message), 16) using hashlib.sha256.
  5. Sign: sig = hd mod n (sign with private key).
  6. Print signature.
  7. Stop.
Algorithm — Verification
  1. Start.
  2. Receive message, signature sig, and public key (e, n).
  3. Recompute hash of message: h = int(SHA-256(message), 16).
  4. Decrypt signature: verify = sige mod n.
  5. If verify == h mod n → print "Signature valid".
  6. Else → print "Signature invalid".
  7. Stop.
Hash Functions & System Programs

SHA-256 Hash & Avalanche Effect

Demonstrates the avalanche effect — small input changes cause drastically different hash outputs.

sha.py
Algorithm
  1. Start.
  2. Read two input strings s1 and s2.
  3. Compute h1 = SHA-256(s1) using hashlib.sha256(s1.encode()).hexdigest().
  4. Compute h2 = SHA-256(s2) similarly.
  5. Print both hex digest strings.
  6. Convert both digests to integers and XOR them: x = int(h1,16) XOR int(h2,16).
  7. Count the number of 1-bits in x using bin(x).count('1') — this is the number of differing bits.
  8. Print the differing bit count.
  9. Stop.
10

File Copy using OS System Calls

Copies a file at the OS level using low-level file descriptors instead of Python's high-level file API.

filecopy.py
Algorithm
  1. Start.
  2. Read source filename and destination filename from user.
  3. Open source file in read-only mode: os.open(source, os.O_RDONLY).
  4. Open (or create) destination file in write mode: os.open(dest, os.O_WRONLY | os.O_CREAT | os.O_TRUNC, 0o644).
  5. Read data from source into buffer: os.read(src, 1024).
  6. Write buffer to destination: os.write(dest, data).
  7. Close both file descriptors using os.close().
  8. Print "File copied successfully".
  9. Stop.

Shell Scripts — Linux Security & Administration

Bash scripts covering user management, file permissions, firewall configuration and system info.

shell/
User Management — user_mgmt.sh
  1. Start.
  2. Use useradd to create a new user with home directory.
  3. Set password using passwd <username>.
  4. Add user to a group using usermod -aG <group> <user>.
  5. Verify by listing user info with id <username>.
  6. Delete user using userdel -r <username> if required.
  7. Stop.
File Permissions — file_perms.sh
  1. Start.
  2. Create a test file and view its permissions using ls -l.
  3. Change permissions using chmod 755 <file> (owner: rwx, group/others: rx).
  4. Change file owner using chown <user>:<group> <file>.
  5. Verify changes with ls -l again.
  6. Stop.
Firewall Rules — firewall.sh
  1. Start.
  2. Check current firewall status: ufw status.
  3. Allow SSH: ufw allow 22.
  4. Allow HTTP/HTTPS: ufw allow 80 and ufw allow 443.
  5. Deny a specific port: ufw deny <port>.
  6. Enable firewall: ufw enable.
  7. Verify rules: ufw status verbose.
  8. Stop.
System Info — sysinfo.sh
  1. Start.
  2. Print CPU info: lscpu or cat /proc/cpuinfo.
  3. Print memory usage: free -h.
  4. Print disk usage: df -h.
  5. Print running processes: top -n 1 or ps aux.
  6. Print OS details: uname -a.
  7. Stop.

🔑 Key Points

Caesar / Vigenère

  • Caesar is monoalphabetic (fixed shift)
  • Vigenère is polyalphabetic (keyword shifts)
  • Both vulnerable to frequency analysis
  • Decryption = reverse shift

Playfair

  • Operates on digraphs (pairs of letters)
  • I and J share one cell in 5×5 matrix
  • Insert X between duplicate pair letters
  • Three rules: same row, col, or rectangle

Hill Cipher

  • Uses matrix multiplication mod 26
  • Key matrix must be invertible mod 26
  • Decryption uses matrix inverse mod 26
  • Resistant to simple frequency analysis

Transposition Ciphers

  • Rearrange characters, do not substitute
  • Rail Fence: zigzag across n rails
  • Columnar: keyword determines column order
  • Decryption reconstructs the original grid

RSA

  • Security relies on integer factorization
  • n = p × q; φ(n) = (p−1)(q−1)
  • Public key (e, n); Private key (d, n)
  • e·d ≡ 1 mod φ(n)

Digital Signature

  • Sign with private key; verify with public
  • Hash ensures message integrity
  • Provides authenticity + non-repudiation
  • sig = hash^d mod n

SHA-256

  • Produces fixed 256-bit output
  • One-way — cannot reverse to input
  • Avalanche effect: 1-bit change → ~50% different bits
  • Used in signatures and integrity checks

OS File Operations

  • os.open is lower-level than open()
  • Returns integer file descriptor
  • Flags: O_RDONLY, O_WRONLY, O_CREAT
  • Always close fd with os.close()
